testware.dev

LLMRAGProductTeam
Website besuchen ↗ Code auf GitHub ↗

LLM+RAG-Plattform, die Nutzern hilft, Digital-Twin-Workflows zu entwerfen. Der Nutzer gibt einen Prompt ein (Branche, Anwendung, Projektart); eine erweiterte Prompt-Pipeline mit LLM+RAG generiert eine Workflow-Beschreibung, ein Flussdiagramm und passende Tools aus einer kuratierten Datenbank; Nutzer können das Ergebnis bearbeiten und speichern.

Teamprojekt — gemeinsam mit Mitesh, Thais und Emanuel. Pauls Beitrag: die RAG-Pipeline und das Fachwissen (Digital Twin / Bautechnik) dahinter.
